# Interface direction

The user requested a neumorphic interface. The direction is a daylight probability instrument: pale sage surfaces, paired soft shadows, recessed amount inputs, forest-green execution controls, and a proportional curve as the primary visual object. This is an operational interface, with the trading task, chain state and provenance visible.

The Impeccable direction seed was considered; the user-pinned material takes precedence. Other visual systems such as teletext and a variable-type specimen lose on product clarity and audience fit here. Their useful disciplines are explicit state labels and a responsive slider with immediate feedback, not borrowed visual motifs.

First viewport: real market status, the named demo question, implied probability, curve illustration and outcome swap control. On small screens navigation becomes a row and columns stack. Typography remains readable; the curve does not claim to be a live depth measurement.

Signature interaction: scrubbing time compresses the illustrated Gaussian liquidity profile. This action explicitly leaves the executable strategy unchanged. Actual quotes, approvals, swaps and receipts are separate states derived from RPC responses.

Constraints: no fabricated trading history or market prices; no guaranteed yield; manual resolution must be visible; keyboard focus, reduced motion and mobile overflow checks are required. No generated raster assets are used. Manrope is self-hosted from its OFL-licensed package.
